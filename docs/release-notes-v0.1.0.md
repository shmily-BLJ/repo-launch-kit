# Repo Launch Kit v0.1.0 Release Notes / 发布说明

## Summary / 概要

Repo Launch Kit v0.1.0 is the first paid-download version of the local AI launch tool.

Repo Launch Kit v0.1.0 是第一个适合打包售卖的本地 AI 发布工具版本。

## Included / 包含内容

- Local React web app
- Local Node API server
- OpenAI-compatible Chat Completions provider settings
- Connection test
- Bilingual launch package generation
- Markdown export
- ZIP export
- Example input and output
- Buyer setup guide
- Provider configuration guide
- Launch checklist

## Not Included / 不包含

- API keys
- Hosted cloud service
- Membership system
- Payment integration
- Product Hunt launch guarantee

## Known Limits / 已知限制

- Some OpenAI-compatible providers return non-standard output.
- Weak models may fail to return valid launch-kit JSON.
- The app is local-first and requires the buyer to run Node.js.

- 有些兼容 OpenAI 的提供商会返回非标准格式。
- 较弱的模型可能无法稳定返回发布包 JSON。
- 工具是本地运行版，需要买家能运行 Node.js。
