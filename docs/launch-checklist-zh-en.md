# Launch Checklist / 发布检查清单

Use this checklist before you publish Repo Launch Kit or any product generated by it.

发布 Repo Launch Kit 或用它生成的新产品前，可以按这个清单检查。

## Product / 产品

- Product name is clear
- One-liner explains the outcome
- Target user is specific
- Problem is concrete
- Price is visible
- Download or access method is clear

- 产品名清楚
- 一句话说明能得到什么结果
- 目标用户具体
- 解决的问题具体
- 价格可见
- 下载或获取方式清楚

## Safety / 安全

- `.env` is not committed
- API keys are not in screenshots
- API keys are not in ZIP exports
- Paid ZIP does not include personal tokens
- Public repo does not include platform payout details

- `.env` 没有提交
- 截图里没有 API Key
- ZIP 导出里没有 API Key
- 付费 ZIP 里没有个人 token
- 公开仓库里没有收款平台敏感信息

## Sales Page / 销售页

- Title says what the product is
- Cover image shows the product
- First paragraph explains who it is for
- Bullet list shows what buyers get
- Notes explain API key requirements
- Refund or support expectation is stated

- 标题说明产品是什么
- 封面图展示产品
- 第一段说明适合谁
- 列表说明买家会得到什么
- 说明需要买家自备 API Key
- 说明退款或支持预期

## Platforms / 平台

- GitHub README is public
- Ko-fi profile has product description
- Afdian product or plan is ready
- MBD product is ready
- Product Hunt and Uneed posts are not launched before checkout is working

- GitHub README 已公开
- Ko-fi 主页有产品介绍
- 爱发电商品或方案已准备
- 面包多商品已准备
- 在收款流程跑通前，不急着发 Product Hunt 和 Uneed

## First Promotion / 第一次推广

- Share GitHub link first
- Mention that paid download is opening soon
- Ask for feedback from 3 to 5 makers
- Do not overpromise automation
- Keep price simple

- 先分享 GitHub 链接
- 说明付费下载即将开放
- 找 3 到 5 个做产品的人要反馈
- 不要过度承诺自动化
- 价格保持简单
